# Lean AI 榜单公司调研简报

## 背景
我们在为 https://leanaileaderboard.com/ 制作一个中文独立看板。该榜单收录「人均营收极高、团队极小」的 AI Native 公司。
你的任务是：为分配给你的每家公司，产出一段结构化中文调研结果（核心价值 / 商业模式 / 护城河 / 最新进展）。

当前日期：**2026-10-19**。请优先采用 2025–2026 的公开信息；榜单快照时间见 CSV 的 Snapshot 列。
榜单数据本身（营收、人数、估值、来源链接）在批次 CSV 里，可作为线索，但不要把它当作唯一事实来源。

## 网络访问方式（重要）
- 优先使用 `web_search` 与 `web_fetch` 工具。
- 若要用 bash 访问外网，必须走系统代理：`curl -x http://127.0.0.1:9567 -sL --max-time 25 "URL"`（不带代理会失败）。
- X/Twitter、LinkedIn 常常抓不到正文，不要死磕；改查官网、公司博客、TechCrunch/The Information/Forbes/Business Insider 等。
- 不要使用浏览器 CDP（当前 Chrome 未连接）。

## 每家公司需要产出 4 个字段
1. `value` —— **一句话核心价值**（≤ 45 个汉字）：这家公司为谁解决什么问题、凭什么值得付费。要具体、有信息量，不要空泛口号（反例：「用 AI 改变行业」）。
2. `model` —— **商业模式**（70–110 字）：客户是谁（B2B/B2C/开发者）、卖什么产品/服务、怎么收费（订阅/按量/佣金/授权）、增长方式。
3. `moat` —— **护城河**（70–110 字）：数据飞轮、分发渠道、成本/效率结构、生态与切换成本、品牌或网络效应。要判断「真护城河 vs 先发窗口」，可以指出薄弱点。
4. `progress` —— **最新进展**（70–110 字）：1–2 条有时间的近期事实（融资、ARR/用户里程碑、产品发布、并购、争议）。没有新消息时，说明「公开信息截至 X」，并给出榜单快照数据作为参照。

另外附：
- `confidence`: `high` / `medium` / `low`（基于信息充分度）
- `sources`: 1–3 个你实际读到/验证过的 URL

## 事实与措辞纪律
- 不编造具体数字、日期、客户名。拿不准就写「据报道/据榜单快照」，并标低置信度。
- 如果公司极度低调、查不到可靠信息：写清「公开信息有限」，商业模式基于其产品/招聘/榜单描述做谨慎推断，confidence 标 `low`，不要瞎编融资细节。
- 遇到争议或负面信息（例如造假指控、裁员、关停），要如实写进 `progress`，这是看板的价值。
- 中文输出，专业、克制、有洞察；不要复制英文原文，不要营销腔。
- 公司名保持 CSV 原样。

## 输出格式
把结果写入指定 JSON 文件（UTF-8，不要 markdown 代码块包裹），结构：

```json
{
  "companies": [
    {
      "name": "Company Name",
      "value": "...",
      "model": "...",
      "moat": "...",
      "progress": "...",
      "confidence": "high",
      "sources": ["https://..."]
    }
  ]
}
```

必须覆盖分配 CSV 里的**每一家公司**，顺序与 CSV 一致。
